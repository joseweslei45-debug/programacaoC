## 📂 Conteúdo

| Arquivo | Descrição |
|--------|-----------|
| `olamundo.c` | Primeiro programa: imprime "olá, mundo" no terminal |

## ▶️ Como compilar e executar

```bash
gcc olamundo.c -o olamundo
./olamundo
```

No Windows (MinGW):

```powershell
gcc olamundo.c -o olamundo.exe
.\olamundo.exe
```
